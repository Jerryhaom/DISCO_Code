# Audit scope and current-version gaps

The source was copied from commit `e7b21b9` without modifying the author's original
repository. This is a local staged working copy, not a published release.

## Verified in this audit

- All R scripts parse; all 63 bundled original plotting blocks and manifest
  entries resolve. This is a syntax/dependency-path check, not controlled-data
  certification.
- Package and calculator examples run against the audited DISCO4HD 0.3.1.
- The new NHANES-calibrated synthetic example creates 400 fictional records and
  base-R visualizations, using aggregate parameters only.
- The web calculator and R package agree on 400 synthetic profiles across five
  comparison distributions, with maximum numerical difference below 1e-12.
- The sensitivity directory was renamed from `08_revision_analyses` to
  `08_sensitivity_analyses`, updating all in-repository paths and manifests.

## Do not confuse historical replay with corrected manuscript analysis

| Entry/family | Actual code evidence | Publication limitation |
|---|---|---|
| `04_external_validation/run_figures.R` and HRS replay blocks | Read legacy saved HRS scores and survival objects | Do not reproduce the new Tracker/NDI endpoints, HRS <60 reference, 35-marker median imputation and ED6 abcd panels. |
| `05_organ_network/run_figures.R`, sensitivity replay block | Read `Tissue.corr.sensitivity.rds`; drawing a heatmap does not reconstruct its residualization | Corrected age/sex residual matrices and related statistics need a separately versioned upstream pipeline. |

| Organ Oh/Goeminne and HRS reference-transfer supplement | Added after this source release | New analyses need portable release modules and private-input contracts before a manuscript-final release. |
| Source gaps in final figure designs | Some final plotting inputs/layout chains remain unidentified | Do not call a candidate or approximate redraw an exact original-code reproduction. |

No new whole-manuscript validation is claimed here. Keep legacy scripts available
for provenance, but do not use a `preferred` label from the earlier release as a
current scientific approval. A release gate remains open until corrected modules
are synchronized and rerun against authorized inputs.
